# House Price Prediction using Machine Learning

## Objective
This project predicts house prices using the Linear Regression algorithm.

## Technologies
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
USA Housing Dataset

## Algorithm
Linear Regression

## Features
- Data Analysis
- Model Performance
- House Price Prediction
- About Page

## Run

pip install -r requirements.txt

python -m streamlit run app.py
